방 앱 연결 예시

방 앱 맨 위에 공통 상단바가 붙고, 버튼을 누르면 events에 기록이 남아 메인 생활관의 식당 창문이 켜집니다.

<link rel="stylesheet" href="https://(통합 사이트 주소)/shared/design.css">
<script src="https://(통합 사이트 주소)/shared/lnl.js"></script>
<script>
  LNL.header('식당');
  button.onclick = () => LNL.emit('cafeteria', 'view_menu');
</script>
